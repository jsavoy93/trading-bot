# Scripts Directory

Utility scripts for the trading bot.

## Available Scripts

### Analysis & Performance
- `performance_analysis.py` - Analyze trading performance and statistics
- `simple_performance_analysis.py` - Simplified performance analysis
- `example_no_ai_analysis.py` - Example of running bot without AI features

### Continuous Trading
- `run_continuous.py` - Run the bot in continuous mode
- `test_ai_connections.py` - Test AI provider connections

## Usage

```bash
# Run performance analysis
python scripts/performance_analysis.py

# Example without AI
python scripts/example_no_ai_analysis.py

# Test AI connections
python scripts/test_ai_connections.py
```

## Archived Scripts

The `archive/` subdirectory contains deprecated debugging and diagnostic scripts.
