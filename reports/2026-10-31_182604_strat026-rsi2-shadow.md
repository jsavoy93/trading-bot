## Strategy implemented (frozen from the STRAT-026 research record)

`experiments/strat_026/run_research.py` (S1a `rsi2_regime`), merged via PR #121.

| Element | Frozen value |
|---|---|
| Entry RSI(2) | `< 10` (Wilder, research-engine formula; RSI left NaN when avg loss = 0) |
| Liquidity gate | vol20 ≥ 1,000,000 AND close ≥ $5 |
| Trend filter | SPY close > SPY SMA200 (regime ON) |
| Entry fill | next trading day's OPEN (t+1) |
| Initial stop | `entry - 2.0 * ATR14(signal day)`, close-checked |
| Chandelier trail | `max(close since entry) - 3.0 * ATR14(signal day)`, close-checked, no lookahead (chandelier updated AFTER the day's stop check) |

| Partial | 50% of position at +2R (`risk = 2.0 * ATR14(t)`) when intraday HIGH touches `entry + 2R`, filled at exactly 2R |
| Time exit | 15 trading days (entry day = day 1) → exit index `entry + 14` |
| Costs | 10 bps/side; logged `net_ret = gross - 20 bps` |
| Anti-overlap | one open hypothetical position per symbol |

## Deviations / risks

1. **Base branch:** task stated `main` includes PR #121 (`7097109`); it does not — PR #121
   merged into `research/strat-023-recheck`. Branch is based on `7097109` so the STRAT-026
   record is present; the PR is opened against `main` per instruction and consequently
   includes PR #121's research files until PR #121 is merged into `main`.
2. **Kill-switch semantics:** strat023 uses an env guard; Josh's task requires an own
   kill-switch *file*. This runner implements both: file `KILL_SWITCH` (exit 3) and the
   `STRAT026_LOG_ONLY=1` env guard (exit 2). The kill file is intentionally NOT committed
   (its presence halts the run).
3. **Timer time:** 21:30 UTC Mon–Fri (15 minutes after strat023's 21:15 UTC) to avoid
   overlapping data fetches; still after the US close in both DST (20:00 UTC) and
   standard time (21:00 UTC).
4. **RSI NaN convention:** the STRAT-026 research engine leaves RSI undefined when the
   average loss is 0 (strat023 substitutes 100). The shadow runner matches the research
   engine exactly so the signal semantics match the record.
5. **Regime lookup:** uses the latest SPY bar at or before the symbol's signal date
   (no lookahead) rather than requiring an exact calendar match.
6. **Partial-fill assumption:** +2R fill assumes intraday-high touch fills at exactly 2R
   (documented optimism in the research record; no intraday data in this repo).
7. **Strategy confidence:** STRAT-026's holdout edge is positive but below the
   pre-declared t_vs_base ≥ 2 bar (1.84). The service only logs hypotheticals and
   places no orders.
8. **Raw-adjustment bars** inherit the documented STRAT-022/026 split-artifact caveat
   (affects per-trade returns, not signal gating).
