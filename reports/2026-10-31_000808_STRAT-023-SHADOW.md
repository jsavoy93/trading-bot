## Risks / caveats
1. Exit fills assume the triggering **close** (same honest-stop convention as
   the backtest); real intraday stop breaches would fill worse.
2. Service `ExecStart` points at `/tmp/strat023-b` because the branch is not
   merged — must be updated to a stable checkout after merge (noted in the
   unit file comment) + `daemon-reload`.
3. Pending signals whose symbol data stops are cancelled (`data_gap` /
   `cancelled` status) rather than retried.
4. Universe/credential files are read from the main workspace path at runtime;
   the runner fails loudly if they are absent.
5. Shadow data is forward-looking paper record only; no performance claims
   beyond PR 116's reported holdout result.
6. Raw (unadjusted) bars — split artifacts possible, same caveat as PR 116.
7. If the machine is off at 21:15 UTC, `Persistent=true` catches the run up
   on next boot.
