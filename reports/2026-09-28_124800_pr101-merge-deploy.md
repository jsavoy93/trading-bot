### BUY CONTRACT (restated from REPORT.md, section 2)
**DAILY BUY CONDITIONS** (all four required simultaneously for
`buy_eligible = True` in `src/core/smart_bot.py`):
1. RSI < `rsi_buy_threshold` (default 30, configurable via settings_service)
2. SMA_fast > SMA_slow (structural; strict greater-than)
3. MACD_histogram > 0 (structural; strict greater-than zero)
4. volume_ratio >= 1.0 (when `enable_volume_confirmation=True`; default True)

`volume_confirmation` is **config-conditional**. CURRENT setting
from `src/core/settings_service.py` line 95-96: `True`.
Production runtime helper `_buy_funnel_required_gates_runtime()`
returns `{rsi_oversold, sma_uptrend, macd_positive,
volume_confirmation}` for the live dashboard.

**MTF** (multi_timeframe, production default):
- daily BUY + hourly BUY  → final BUY emitted (proceed to ranking)
- daily BUY + hourly unavailable → daily_only mode, final BUY OK
- daily BUY + hourly HOLD/SELL (disagreement) → final HOLD with
  `decision.outcome = HOLD_INELIGIBLE`, `timeframe_mode =
  multi_timeframe`, `signal_strength = WEAK`
- The MTF trigger is **code-path inference**, not directly persisted
  (see dashboard `hold_reason_buckets.MTF_DISAGREEMENT`).

**SCORE:**
- `scoring.total_score` does NOT gate BUY eligibility (SCORE-002).
- `total_score` participates ONLY in STRONG (>=65) vs MEDIUM
  signal-strength discrimination AFTER `signal == "BUY"` is emitted.

**BUY REACHABLE: YES** (verified by 12 deterministic tests in
`tests/test_signal_emission_buy_reachability.py`, all PASS at
deployment time and unchanged by the merge).
