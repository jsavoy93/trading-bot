## 1. SCOPE CONFIRMATION

**Observability-only change. Existing trading behavior is preserved bit-for-bit.**

Allowed changes per owner task:
- Modify score-component validation path so the exact failure reason is available to the caller.
- Propagate the reason through `analyze_symbol` and `analyze_multi_timeframe`.
- Persist the reason on `SKIPPED_INVALID_DATA` terminal decisions.
- Add tests proving each fail-closed case carries a stable token.

Disallowed (none touched):
- Score calculations, indicator calculations, NaN→zero substitutions in strict paths.
- Relaxing fail-closed validation.
- BUY/HOLD/SELL thresholds, strategy gates, fallback HOLD behavior.
- Symbol-universe filtering, ban mechanism, cooldowns.
- Suppressing `SKIPPED_INVALID_DATA`.
- Fixing MACD/ATR/BB or upstream market-data issues.

The OBS-001 schema version remains `1`. The new field is opt-in: existing callers that don't pass the kwarg see no change. The original `_score_components` and `_clamp_total_score` return signatures are unchanged for backward compatibility.

    self, latest, catalyst_score=0.0,

    """Returns (components_or_None, reason_token_or_None).
    Collects ALL invalid fields into a comma-joined stable-order list
    so dashboards can attribute multi-field failures cleanly.
    """

def _clamp_total_score_with_reason(

    """

**Existing helpers** (backward-compatible thin wrappers):

```python
def _score_components(self, latest, catalyst_score=0.0) -> Optional[Dict]:
    components, _reason = self._score_components_with_reason(latest, ...)
    return components

def _clamp_total_score(self, raw_score) -> Optional[float]:
    value, _reason = self._clamp_total_score_with_reason(raw_score)
    return value
```

All 86 pre-existing tests in `test_smart_bot_score_normalization.py` (including the 10 `_returns_none_when_*` fail-closed tests) pass unchanged. The original `None`-on-failure contract is preserved.

### Reason propagation

A new instance attribute `self._last_score_error_reason: Optional[str]` holds the most recent fail-closed reason. It is:
- Initialized to `None` in `__init__`.
- Cleared to `None` at the start of `analyze_symbol()` and `analyze_multi_timeframe()` so a stale value from a prior symbol/cycle cannot leak.
- Set to the fail-closed reason immediately before the function returns `None` from any of the score-component or clamp paths.

The 5 return-`None` sites inside `analyze_symbol` and 5 sites inside `analyze_multi_timeframe` are updated to set the scratch field. The 1 insider-boost clamp site is also updated.

### Persistence

`_persist_skipped_terminal_decision(...)` now accepts an optional `score_error_reason: Optional[str] = None` kwarg.

The new field is forwarded into the `scoring` block of the snapshot:

```python
scoring_block = {
    ...
    "score_invalid_data": ...,
}
if analysis.get("score_error_reason") is not None:
    scoring_block["score_error_reason"] = analysis["score_error_reason"]
```

The explicit kwarg overrides any analysis-dict field (defensive against stale values).

### Call-site wiring

All four SKIPPED_INVALID_DATA call sites in the main loop now pass a `score_error_reason`:

| Site | Token |
|---|---|
| `if df is None or len(df) < self.sma_slow:` (no market data upstream) | `no_market_data` |
| NaN-guard inside fallback score compute | `fallback_nan` |
| Fallback HOLD score path (the main `analyze_symbol returned None` path that produced the 786 rows) | `getattr(self, "_last_score_error_reason", None) or "score_components_unknown"` |
| Outer per-symbol `except Exception` (catch-all) | `analysis_body_exception` |

WEAK / CONFLICTED HOLD_INELIGIBLE rows are NOT touched — they have real scores and `score_error_reason` is not applicable.

The HOLD_INELIGIBLE path does NOT receive a `score_error_reason`. The OBS-002 test `test_score_error_reason_omitted_for_hold_ineligible` proves the field is absent when not supplied.

```sql
SELECT
  json_extract(decision_snapshot, '$.scoring.score_error_reason') AS reason,
  COUNT(*) AS rows
FROM decision_history
WHERE cycle_start >= datetime('now', '-1 hour')
  AND json_extract(decision_snapshot, '$.decision.outcome') = 'SKIPPED_INVALID_DATA'
GROUP BY reason
ORDER BY rows DESC;
```

Expected shape: a small number of distinct reason tokens (likely 1-3) plus a mix of legacy SKIPPED_INVALID_DATA rows from before the deploy that have `score_error_reason = NULL` or absent. NULL rows are pre-deploy artifacts.

```sql
SELECT
  COUNT(*) AS total,
  SUM(CASE WHEN json_extract(decision_snapshot, '$.scoring.score_error_reason') IS NOT NULL
           THEN 1 ELSE 0 END) AS with_reason,
  SUM(CASE WHEN json_extract(decision_snapshot, '$.scoring.score_error_reason') IS NULL
           THEN 1 ELSE 0 END) AS without_reason
FROM decision_history
WHERE cycle_start >= datetime('now', '-1 hour')
  AND json_extract(decision_snapshot, '$.decision.outcome') = 'SKIPPED_INVALID_DATA';
```

This second query tells the owner what fraction of new SKIPPED rows now carry the reason.
