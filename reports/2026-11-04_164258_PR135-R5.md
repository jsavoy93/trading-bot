## Detailed risks

1. **Journal dependency in the execute gate.** Primary evidence is the host
   user journal (`journalctl --user -u strat023-c4-shadow.service --since
   "<today> 21:00:00 UTC"`). If the user journal is unavailable/empty AND the
   C4 DB stayed silent (zero-signal day), the gate refuses the --execute run.
   Fail-loudly, not unsafe, but it can block a legitimate zero-signal day.
   Alternative considered and rejected: the C4 DB alone (silent on zero-signal
   days).
2. **Evidence window starts at 21:00 UTC.** A manual C4 run earlier in the day
   (e.g. 02:26) does not unlock the gate — intended, so only the scheduled
   run counts.
3. **Re-placed stop can be rejected.** The reconciliation re-places the stop
   at the recorded stop price; if the market has gapped below it, the broker
   may reject. The run then logs "POSITION UNPROTECTED" and
   `place_stops_after_fill` retries/re-prices in the same run (market sell on
   a gap). Not fully exercised end-to-end for the rejection path.
4. **New label shape `-stopgap-r<gen>`.** `parse_label` handles it (test
   `test_stopgap_replace_label_parses_for_attribution`), but
   `experiments/swing_paper/report_pnl.py` attribution was NOT re-verified
   against this shape in round 5.
5. **Lint tools unavailable** on the host (flake8/pyflakes not installed), so
   style was verified by `py_compile` + `git diff --check` only.
6. **No independent reviewer-agent verdict** was obtained in this session
   (Josh asked for direct work in this session, no worker). ENG-07 review
   gate is still outstanding before any merge request.
