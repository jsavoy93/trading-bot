# Tests Directory

This directory contains test scripts for the trading bot.

## Active Tests

- `test_no_trade_reasons.py` - Demonstrates the detailed no-trade reasons feature
- `test_ticker_criteria.py` - Shows per-ticker failure criteria for major stocks

## Running Tests

```bash
# Test no-trade reasons feature
python tests/test_no_trade_reasons.py

# Test ticker criteria analysis
python tests/test_ticker_criteria.py
```

## Archived Tests

The `archive/` subdirectory contains older test files that are kept for reference but are no longer actively used:
- Legacy Hugging Face API tests
- Old AI provider tests
- Debug and diagnostic scripts
